# How to play and how to run it

## Run it
- **Online:** open the GitHub Pages link in the [README](../README.md). Nothing to install, no account.
- **Offline:** download the repository as a ZIP (**Code → Download ZIP**), unzip it and double-click `game/dist/mars-outpost.html`.
- **Do not** open the HTML file from GitHub's file viewer: it shows the source code, not the game.
- Works on phones, tablets and computers with a modern browser. Sound starts after the first tap, because browsers block audio until you interact. Use the 🔊 button to mute.

## Goal
Keep the Mars base running and launch the spaceship, while deciding what to protect. **Every decision has a consequence, good or bad.** There is no perfect answer.

## Meters
| Meter | Meaning |
|---|---|
| ⚡ Energy | Power at the base |
| 🍎 Food | Food supply. It only grows in the Greenhouse |
| 🛠️ Equipment | Condition of machines and systems |
| 👩‍🚀 Health | The astronaut's health. At 0 the mission is over |
| ⏳ Time | Time left in the day |
| 📊 Data | Science data collected on the Expedition |

## The map
Tap a place to open it. Each place can be used once.

| Place | What you decide |
|---|---|
| Habitat | How much maintenance to do on life support, computers and communications |
| Greenhouse | Which plant conditions (temperature, humidity, lighting) to control |
| Solar panels | How to react to a solar storm |
| Robot garage | How to prepare a robot job |
| Expedition | How much risk to take to collect data. Needs enough Food |
| Laboratory | Opened from the Expedition after it is done: analyze the data and send it to Earth |
| Spaceship | Launch, when the base is ready |

## Random events
A **solar storm** or a **dust storm** can arrive at a random moment, so no two games are the same. A pop-up with a countdown bar appears over the map. Choose an option before the time ends; if you do nothing, the base does nothing. After you choose, the game shows the consequence and the real science behind it.

## How the game ends
- **Launch:** the ship launches when the Habitat, Greenhouse, Solar panels, Robot garage and Expedition are done, and Energy, Food, Health, Time and Data are each at least 1. A **mission log** shows *What you protected* and *What it cost*.
- **Mission over:** when Health reaches 0. The game explains the real science about the risk and lets you try again.
- **Dead end:** if the ship can never launch (for example, the fast lab analysis wiped all the data), the game says so and offers to start again.

## The science
Press **🔭 Is this real? The science behind it** in any place or event, or the **📚** button, to see the text and the official source (NASA / JPL-Caltech or the Canadian Space Agency). The sources are also in [nasa-data-sources.md](nasa-data-sources.md) and [CREDITS.md](../CREDITS.md). All science text is curated, not live data; chances, costs and timers are game design values.

## A short tour for judges
1. **Greenhouse** first: pick an option and see how Food changes. Try the other options in another game to compare.
2. **Habitat, Solar panels and Robot garage:** each option has a different consequence.
3. **Expedition:** it stays locked if Food is too low. Then compare the two options: more data with a safer choice, or all the data with a risk of losing everything.
4. **Laboratory** (opened from the Expedition): fast or careful analysis.
5. Watch for a **storm pop-up** at any point, and open **🔭 Is this real?** to see the source.
6. **Spaceship:** launch and read the mission log.
7. Play again to see different events and outcomes.
