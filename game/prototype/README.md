# Prototype (Twine)

`Mission_Trainer.twee` is a **raw, playable prototype** made with Twine (Harlowe 3.3). It is used to test the rules and the text before the real game is written in JavaScript in `game/src/`. It is not the final game.

## Play it
1. Install [Twine 2.6+](https://twinery.org/) (or use the web version).
2. **Library → Import** and choose `Mission_Trainer.twee`.
3. Press **Play**.
