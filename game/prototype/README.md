# Prototype (Twine)

`Mission_Trainer.twee` is the **final version of the playable prototype** made with Twine (Harlowe 3.3). It is used to test the rules and the text before the real game is written in JavaScript in `game/src/`. The real game will be the JavaScript version.

## Play it
1. Install [Twine 2.6+](https://twinery.org/) (or use the web version).
2. **Library → Import** and choose `Mission_Trainer.twee`.
3. Press **Play**.

The values the prototype uses and how they differ from `game/data/` are in [../../docs/prototype.md](../../docs/prototype.md).
