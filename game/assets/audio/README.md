# Audio

- `music.mp3`: "Alone in Space with Only Your Decisions", original song by the team. Background music for the whole game (loops). Trimmed (starts at second 17 of the original; 2 s of silence removed at the end) and re-encoded to 128 kbps so the page loads fast.

To change the song, replace `music.mp3` with another file of the same name and run `npm run build`. Every file here must be listed in `../../../CREDITS.md` with title, author, link and license. See `../../../docs/audio.md`.
