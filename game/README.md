# Game

All game code, data and assets live here.

```
data/     events.json, stations.json (content and design values)
src/
  engine/ game logic (no graphics)
  game/   map, stations
  ui/     pop-up windows and bars
tests/    automated checks
prototype/ raw Twine version (Mission_Trainer.twee) used to test rules
assets/   sprites, tilemaps, audio, ui
```

Status: content data is defined; a Twine prototype exists in `prototype/`; the JavaScript code is under development.
